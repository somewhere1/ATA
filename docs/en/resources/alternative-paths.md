# Alternative Paths: Joining Anthropic Without a PhD

> For those with exceptional engineering skills or significant open-source impact

---

## Path 1: Open Source → Research Engineer

Anthropic's Research Engineer role is equally important as Research Scientist, with more relaxed academic requirements.

### Open Source Project Threshold

- GitHub Stars > 500 with active users and contributors
- Solves a real pain point in AI Safety / Interpretability
- High code quality with complete documentation and tests
- Organically cited in the community (forums, tweets, papers)

### Suggested Project Directions

| Direction | Reference Project |
|-----------|------------------|
| Mech Interp toolkit | TransformerLens |
| SAE training framework | SAELens |
| RLHF infrastructure | trl, OpenRLHF |
| Evaluation framework | lm-eval-harness |
| Visualization tools | CircuitsVis |

---

## Path 2: Big Tech → Transfer

Work at **Google DeepMind / Meta FAIR / OpenAI** for 2-3 years, then transfer to Anthropic. During this time, publish 1+ paper and maintain Alignment Forum visibility.

---

## Path 3: Independent Researcher

Extremely high bar, but possible with funding from Long-Term Future Fund, SFF, or Open Philanthropy.

---

## Comparison

| | Open Source RE | Big Tech Transfer | Independent |
|--|--------------|------------------|-------------|
| **Difficulty** | High | Medium | Very High |
| **Timeline** | 2-3 years | 4-6 years | Variable |
| **Risk** | Medium | Low (big tech fallback) | Very High |
| **Best for** | Top engineers | Steady growth | Extremely self-driven |

**Regardless of path, the core is: build visibility and contribution records in the AI Safety community.**
