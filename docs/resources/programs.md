## 🟢 零基础也能参加

### Apart Research Hackathons（强烈推荐入门）

**最适合第一次参与 AI Safety 研究的人。**

| 信息 | 详情 |
|------|------|
| **形式** | 线上，2-3 天，团队协作 |
| **频率** | 几乎每月一次 |
| **门槛** | 无，提供代码模板和灵感 |
| **产出** | Workshop 级别论文雏形 |
| **链接** | [apartresearch.com/sprints](https://apartresearch.com/sprints) |

**近期 / 即将开始的 Hackathons：**

| Hackathon | 时间 | 方向 |
|-----------|------|------|
| AI Control Hackathon 2026 | 2026年3月20-22日 | AI 控制协议设计、红队测试 |
| Mechanistic Interpretability Hackathon | 定期举办 | Mech Interp 开放问题 |
| ARENA x Apart Mech Interp Hackathon | 配合 ARENA 课程 | Mech Interp |

::: tip 为什么推荐 Apart Hackathon
- 可以在中途加入，不需要从头参加
- 提供代码 starter、ideas 和 inspiration
- 与 Redwood Research、UK AISI 等机构联合举办
- 产出的论文可以直接投 Workshop
:::

### Anthropic Fellows Program ⭐⭐⭐

**直接在 Anthropic 做研究！**

| 信息 | 详情 |
|------|------|
| **形式** | 全职 4 个月，远程或 SF/London |
| **待遇** | 每周 $3,850 + $15k/月 compute + Anthropic 导师 |
| **门槛** | 强技术背景，不需要 PhD 或论文 |
| **方向** | Scalable Oversight / Adversarial Robustness / AI Control / Mech Interp / Model Organisms / AI Security |
| **成果** | 40%+ Fellow 后续加入 Anthropic 全职，80%+ 发表论文 |
| **链接** | [alignment.anthropic.com](https://alignment.anthropic.com/2025/anthropic-fellows-program-2026/) |

::: warning 关键信息
Anthropic 更看重你的执行能力而非背书。强候选人通常有：技术基础扎实、能把模糊问题变成具体进展、能清晰思考困难技术问题。
:::

## 推荐入门路径

```
完全新手
    → BlueDot AI Safety Fundamentals（8周，建立概念框架）
    → Apart Research Hackathon（第一次动手做研究）
        ↓
有 Python/ML 基础
    → ARENA（5周，Mech Interp 技术入门）
    → SPAR 或 AI Safety Camp（3个月，配对研究项目）
        ↓
有研究经验
    → MATS（10周，伯克利，最强跳板）
    → Anthropic Fellows（4个月，直接在 Anthropic 做研究）
```
