# 🎯 Aim to Anthropic

> 一份为「背景普通、有开源经验」的研究者准备的 Anthropic 进入路线图与学习资源库。

**🌐 在线学习网站：[somewhere1.github.io/ATA](https://somewhere1.github.io/ATA/)**

**起点假设：** 无论文 · 开源项目 × 1 · QS 1200+ Master · CET-6

---

## ✨ 网站功能

- **三阶段学习路线** — 从数学基础到 Anthropic 实习，覆盖 0-5 年完整路径
- **互动测验** — 50+ 道知识检测题，测试你对每个主题的理解
- **进度追踪** — 持久化的 Checklist，记录你的学习进度
- **写作练习** — 论文摘要、SOP、研究笔记的写作训练
- **时间线** — 会议截止日期、MATS 申请窗口、博士申请节点
- **成功案例** — 不同背景的人如何进入 AI Safety 领域
- **每周推荐论文** — AI Safety / Interpretability 领域的精选论文导读
- **中英双语** — 支持中文和英文界面
- **暗色模式** — 支持深色主题
- **全文搜索** — 快速找到任何资源

---

## 📋 路线概览

```
现在的你
（开源项目 · Master在读 · CET-6 · 无论文）
        ↓
第一阶段（0–12个月）
夯实数学 & 深度学习理论 · 扩展开源项目至 AI Safety 方向 · 积累英语学术写作
        ↓
第二阶段（12–24个月）
AI Safety 技术入门 · 发第一篇论文（Workshop / arXiv）· 申请 MATS · 连接研究社区
        ↓
第三阶段（3–5年，博士期间）
顶会论文（NeurIPS / ICML / ICLR）· Anthropic 暑期实习 · 方向专精（Alignment / Interp）
        ↓
进入 Anthropic
（Research Scientist · Research Engineer · Alignment Researcher）
```

> **备选路线：** 若开源影响力极大，可跳过博士直接申 Research Engineer；或先入 Google DeepMind / Meta FAIR 积累后跳槽。

## 🛠 技术栈

- **[VitePress](https://vitepress.dev/)** — Vue 驱动的静态网站生成器
- **Vue 3** — 自定义交互组件（Quiz、Checklist、WritingExercise 等）
- **GitHub Pages** — 自动部署
- **localStorage** — 客户端进度持久化

---

## 💻 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run docs:dev

# 构建生产版本
npm run docs:build

# 预览生产版本
npm run docs:preview
```
